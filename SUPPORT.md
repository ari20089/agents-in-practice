# Support

## Community support policy

This repository is maintained by a volunteer. The skills are provided as-is. They are **not Microsoft products**, do not include official Microsoft support, and do not come with a service-level agreement. Help is offered on a best-effort basis.

## Before requesting help

1. Open the skill's folder and read its `README.md`: prerequisites, limitations, and the documentation date it relies on.
2. Confirm you are using the intended host (GitHub Copilot, Copilot Studio, Microsoft 365 Copilot) and that your tenant, licence, permissions and organisational policies meet the skill's requirements.
3. Search the [existing issues](https://github.com/ari20089/agents-in-practice/issues) for the skill name and the error.
4. Remove secrets, personal data, customer content and tenant identifiers before sharing diagnostics.

## Open a repository issue when

- a specific skill contains incorrect, outdated or incomplete instructions;
- a skill's folder, references or catalog entry is broken;
- you can provide reproducible steps for a skill-specific problem;
- you want to request a new skill.

Use the matching [issue form](https://github.com/ari20089/agents-in-practice/issues/new/choose) and include the skill name, expected result, actual result, reproduction steps and non-sensitive environment details.

## Use other channels when

- you have a Microsoft 365, Copilot Studio, Purview or licensing question: use [Microsoft Learn](https://learn.microsoft.com/) or your Microsoft support channel;
- you suspect a security vulnerability: follow [SECURITY.md](./SECURITY.md).
